# familymeal-rebuild

家庭食谱 App（`com.familymeal.app`，v0.1.0）的**逆向评估与重建工作区**。原始源码与签名密钥已随构建机丢失，目标是以设计文档为规格书，在本机重建到功能等价（建议版本号 0.2.0）。

## 目录内容

| 文件/目录 | 说明 |
|---|---|
| `familiymeal-design-v3.md` | 规格书（设计文档 v3）——公式、约束、校验规则、表结构、P0–P7 各阶段验收标准。**与反编译产物冲突时以本文档为准** |
| `familymeal-逆向还原评估.md` | 2026-11-16 静态反编译评估报告：混淆程度、已还原资产清单、混淆名→功能映射表 |
| `familymeal-重建施工计划.md` | 重建施工计划（P0–P7 阶段划分与前置条件） |
| `familymeal-0.1.0-反编译包.zip` | jadx 1.5.6 反编译树打包（3811 个混淆类，参考实现）；包内 `persons.json` 年龄已脱敏（非真实值），已解包至 `reference/` |
| `reference/` | 反编译源码树：`sources/`（3919 个混淆 Java 类）+ `resources/`（资源与种子 JSON）。仅供阅读参考，**不可构建**；重建代码在 `solver/` 等模块中产生 |
| `solver/` | **P0 求解器（已交付，可构建可运行）**：core:solver 的 JVM 移植（Java 17 + ojAlgo 57.7.0，依赖已入库），模型规格、类名映射与验收结果见 `solver/README.md` |
| `familymeal-0.1.0.apk.1.apk.1_tmp.apk.1_tmp` | 原始 APK 样本——**仅本地留存，不入库**（assets 内嵌真实成员档案） |
| `ingredients.json` / `recipes.json` / `schedule.json` | 种子数据（入库）：89 食材 / 75 菜谱 / 7×3 时间表；`persons.json`（成员档案）含家人隐私，**仅本地留存** |
| `example/` | 「学霸养成系统」参考截图——**仅本地留存，不入库**（含家人学习记录） |

## 当前状态

- ✅ **反编译完成**（2026-11-16）：数据层 100% 拿回；业务逻辑约九成可读；详见评估报告；反编译源码已解包至 `reference/`
- ✅ **P0 求解器移植完成**（2026-11-17）：硬约束 0 违规；PYTHON_PARITY 口径 11 月目标值 849.03，命中文档最优解（856.67 = 最优×1.009）；限时 3 秒差 0.001% ≤ 0.9%；详见 `solver/README.md`

## 关键结论速览

- R8 全量混淆，`mapping.txt` 不在 APK 内；字符串常数、中文报错文案、控制流全部幸存
- 混淆名→功能锚点：`rs2.java`=营养目标计算、`fk/yj.java`=备份编解码、`7700`=智能调整
- 数据库 schema 12 张表全量还原（`defpackage/ja2.java`）

## 约定

- 家人隐私内容一律不入库：真机备份 JSON（身体数据，放 `data/`）、成员档案 `persons.json`、真机截图 `example/`、原始 APK（内嵌真实成员档案）均仅本地留存
- 远程仓库：GitHub 与 Gitee 双远程，均为**公开仓库**，欢迎协作（Issue / PR）；家人隐私内容仍仅本地留存
